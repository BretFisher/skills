# Roadmap

Open work lives in [GitHub Issues](https://github.com/BretFisher/skills/issues), not in this file.
Issues are the source of truth for features, bugs, and milestones: each item carries its own
discussion, a PR can close it, and other people can see and comment on the backlog.

One label per skill (`github-actions-workflow-pro`, `docker-pro`, `super-linting`, `screencapture`)
marks which skill an issue belongs to. A shortcut skill that only calls another one (`gha-audit`)
carries the label of the skill it calls. An issue with no skill label is repo-wide work: the eval
harness, CI, or the docs.
